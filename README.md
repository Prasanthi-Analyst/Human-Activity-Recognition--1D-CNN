# Human Activity Recognition Using a 1D CNN

## Objective
To develop a 1D Convolutional Neural Network (CNN) that recognizes human physical activities using smartphone sensor data.

## Problem Statement
Recognizing human activities from sensor readings can help with fitness tracking, healthcare monitoring, and activity analysis. This project uses deep learning to classify six activities based on accelerometer and gyroscope signals.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Activities Classified
1. Walking
2. Walking Upstairs
3. Walking Downstairs
4. Sitting
5. Standing
6. Laying Down

## Methodology
1. Load the smartphone sensor dataset.
2. Preprocess the sensor signals and labels.
3. Build a 1D CNN model.
4. Train the model using training data.
5. Evaluate test accuracy and classification metrics.
6. Visualize training performance and the confusion matrix.
7. Predict human activity using the trained model.

## Results
The model's test accuracy, classification report, training graphs, and confusion matrix are generated during execution.

## Dataset
UCI Human Activity Recognition Using Smartphones:
https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones

## How to Run
Open the notebook in Google Colab, execute the cells in order, and review the evaluation results.
